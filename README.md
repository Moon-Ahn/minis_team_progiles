# 이음청년목장 사역팀 소개서

사역팀장님들이 각자 팀을 소개하는 내용을 직접 채워 넣고, **A4로 인쇄하거나 PDF로 저장**하는 페이지입니다.
사역팀을 잘 모르시는 분께 보여 드릴 인쇄물을 만드는 것이 목적입니다.

빌드 도구가 없는 정적 사이트라 `index.html`을 브라우저로 바로 열어도 돌아가고, Vercel에 그대로 올라갑니다.

---

## 1. 쓰는 법 (사역팀장님용)

1. 왼쪽에서 자기 사역팀 탭을 고릅니다.
2. 기본 정보 → 비전 → 핵심가치 → 주요 사역 → 사진 순서로 채웁니다.
   입력하는 대로 자동 저장되고, 탭 옆 숫자가 작성률입니다.
3. **주요 사역**과 **핵심가치**, **사진**은 `+` 버튼으로 얼마든지 늘릴 수 있습니다.
   사역은 `↑ ↓`로 순서를 바꿉니다.
4. 사진은 칸을 클릭하거나 파일을 끌어다 놓으면 됩니다. 알아서 작게 줄여 저장합니다.
5. 다 되면 **「이 팀 인쇄 · PDF」**. 인쇄창에서 프린터 대신 *PDF로 저장*을 고르면 PDF가 됩니다.
   (`Ctrl+P`, 맥은 `⌘P` 로도 바로 열립니다.)

**「전체 소책자」** 버튼은 표지 + 모든 사역팀을 순서대로 이어 붙여 한 번에 인쇄합니다.
안 채운 항목은 인쇄본에서 알아서 빠지므로, 빈칸이 그대로 찍힐 걱정은 없습니다.

인쇄 설정은 따로 건드리실 것이 없습니다. 팀 색 인장과 번호 배지는 «배경 그래픽» 설정을 꺼도 그대로 인쇄됩니다.

---

## 2. 저장 방식 두 가지

오른쪽 위 칩에 현재 상태가 표시됩니다.

| 표시 | 뜻 |
|---|---|
| **이 기기에만 저장** | `config.js`가 비어 있음. 입력 내용이 그 브라우저에만 남습니다. 혼자 작성하거나 시험해 볼 때. |
| **함께 쓰는 중** | Supabase 연결됨. 여러 팀장님이 같은 주소에서 각자 팀을 채우고, 서로의 변경이 실시간으로 보입니다. |

여러 분이 같이 쓰실 거라면 아래 3번을 따라 Supabase를 붙여 주세요.
붙이지 않으면 각자 자기 브라우저에만 저장되어 취합이 안 됩니다.

---

## 3. Supabase 붙이기

10분이면 끝납니다.

1. [supabase.com](https://supabase.com)에서 프로젝트를 새로 만듭니다.
2. 대시보드 → **SQL Editor** → `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**.
   표 하나, 실시간 설정, 사진 보관함(`team-photos`)이 한 번에 만들어집니다.
3. 대시보드 → **Project Settings → API** 에서 두 값을 복사해 `config.js`에 넣습니다.

   ```js
   window.EUM_CONFIG = {
     supabaseUrl: 'https://xxxxxxxxxxxx.supabase.co',
     supabaseAnonKey: 'eyJhbGciOi...'
   };
   ```

   `anon` 키는 브라우저에 공개되는 것이 정상입니다. 레포에 커밋해도 됩니다.
   `service_role` 키는 **절대** 넣지 마세요.
4. 새로고침해서 칩이 «함께 쓰는 중»으로 바뀌면 끝입니다.

### 데이터가 들어가는 곳

- `team_profiles` 표 — 팀당 한 줄, 내용 전체가 `data` (jsonb)에 들어갑니다.
- `team-photos` 스토리지 — 사진 파일. 경로는 `<팀id>/<photos|docs>-<칸번호>-<시각>.webp`.
  사진을 바꾸거나 지우면 이전 파일도 같이 정리합니다.

### 더 잠그고 싶다면

기본 스키마는 **주소를 아는 사람이면 누구나 읽고 쓸 수 있는** 설정입니다.
교회 내부에서 링크를 공유해 쓰는 용도라면 대개 이 정도로 충분하지만, 공개 주소에 올리실 거라면
Supabase의 익명 로그인이나 이메일 로그인을 켜고, `schema.sql`의 정책에서 `using (true)` 부분을
`using (auth.role() = 'authenticated')` 로 바꾸시면 됩니다.

## 4. Vercel 배포

빌드가 없으므로 설정할 것이 거의 없습니다.

```bash
git init
git add .
git commit -m "이음청년목장 사역팀 소개서"
git remote add origin <레포 주소>
git push -u origin main
```

Vercel에서 **New Project → 이 레포 선택**, 그리고

- Framework Preset: **Other**
- Build Command: 비움
- Output Directory: 비움 (레포 최상위가 그대로 사이트가 됩니다)

`config.js`를 커밋해 두면 배포된 사이트가 그대로 Supabase에 연결됩니다.

## 5. 사진 압축

사진은 브라우저에서 올리기 전에 줄입니다.

- 가장 긴 변 **1600px**로 축소 — A4 가로 폭(180mm)에 놓으면 약 **225dpi**라 인쇄에 충분합니다.
- **WebP**로 변환 (지원하지 않는 브라우저는 JPEG). 화질 0.85에서 시작해 한 장 **280KB** 아래로 떨어질 때까지 단계적으로 낮춥니다.
- 그래도 크면 해상도를 한 단계 더 줄여 다시 시도합니다.

보통 3~5MB짜리 휴대폰 사진이 150~250KB로 줄어듭니다. 사진 칸 오른쪽 아래에 실제 용량이 표시됩니다.
값을 바꾸시려면 [`assets/app.js`](assets/app.js) 맨 위의 `MAX_PX`, `TARGET_KB`를 고치세요.

세로로 찍은 사진이나 세로형 포스터도 **잘리지 않습니다.** 틀 안에 비율을 지켜 넣고 남는 자리는 여백으로 둡니다.

## 6. 파일 구조

```
index.html            화면 구조
config.js             Supabase 주소·키 (비우면 로컬 저장)
assets/styles.css     화면 스타일 + A4 인쇄 스타일(@media print)
assets/store.js       저장 계층 — Supabase / localStorage 자동 전환
assets/app.js         편집기, 사진 압축, 인쇄본 생성
supabase/schema.sql   표·정책·스토리지 버킷 초기 설정
preview/              인쇄 점검용 PDF 샘플 (git에 올라가지 않습니다)
```

인쇄본은 화면을 그대로 찍는 것이 아니라 `app.js`의 `teamPrintHtml()`이 따로 만들어 냅니다.
그래서 빈 항목이 사라지고, 표가 페이지 경계에서 알맞게 잘립니다. 인쇄 모양을 고치실 곳은
`styles.css`의 `@media print` 블록입니다.

주소 끝에 **`?print=all`** (또는 `?print=1`)을 붙여 열면 인쇄본이 미리 만들어진 상태로 뜹니다.
바로 `Ctrl+P` 하시면 되고, 인쇄 모양을 손볼 때 확인용으로 쓰기 좋습니다.

## 7. 사역팀 목록 바꾸기

기본 여섯 팀(선교 / 예배 / 미디어선교 / 기도 / 양육 / 새가족)은 `assets/app.js`의 `PRESETS`에 있습니다.
팀 이름은 페이지에서 바로 고칠 수 있고, 팀 자체를 늘리는 것은 왼쪽 **「+ 사역팀 추가」**로 하시면 됩니다.
`PRESETS`는 처음 한 번 채울 때만 쓰입니다.

첫 번째 팀(선교팀)은 **작성 예시**로 채워져 있습니다. 「전부 비우기」를 누르거나, 그냥 위에 덮어쓰시면 됩니다.
